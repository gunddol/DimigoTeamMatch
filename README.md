# 팀 빌딩 (수업용)

구글 폼 응답이 쌓인 **구글 스프레드시트 URL**을 입력하면 데이터를 불러오고, 버튼 한 번으로 2인 1팀을 자동 생성하는 **정적 웹 페이지**입니다.

## 구성

```text
DimigoTeamMatch/
├─ index.html
├─ styles.css
├─ app.js
└─ README.md
```

## 사용 방법
- **구글 스프레드시트(응답) URL**을 입력하고 `URL로 불러오기`
- `팀 매칭 시작` → 모달에서 팀이 하나씩 생성
- 생성 완료 후, 페이지 하단의 결과판에서 팀을 확인

## 설문(응답 시트) 컬럼
아래 질문형 헤더도 자동 인식합니다.
- `타임스탬프`
- `이름을 입력해주세요.`
- `과를 선택해주세요.`
- `희망하는 역할을 선택해주세요.` (예: `Product Designer`, `Release Engineer`, `상관없음`)
- `만들고 싶은 사이트의 주제를 선택해주세요.`

## 참고
- 구글 시트는 브라우저 정책 때문에 CSV `fetch`가 막히는 경우가 있어, 이 프로젝트는 **gviz(JSONP) 방식**으로 URL 데이터를 불러옵니다.
